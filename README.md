# مصحفي | MOSHAFI — تطبيق القرآن الكريم المتكامل (PWA)

تطبيق ويب تقدمي (PWA) متكامل لقراءة القرآن الكريم بالنص العثماني (رواية حفص عن عاصم) من Quran.com API، مع مشغل صوتي داخلي مستمر، ومزامنة الآيات (والكلمات حيث تتوفر توقيتاتها) مع التلاوة، وتفسير لحظي مدمج، ونظام تنزيلات للعمل الكامل بدون إنترنت.

## المميزات المنفذة فعليًا

1. **الهوية البصرية وسهولة الاستخدام (Accessibility & RTL):**
   - لوحة ألوان هادئة: أوف وايت (`#FAF8F3`)، أخضر إسلامي داكن (`#0F3D2E`)، وذهبي هادئ (`#C6A86B`).
   - دعم كامل للاتجاه من اليمين إلى اليسار (`RTL`)، والوضع الليلي والنهاري.
   - **الوضع المبسط (كبار السن):** زر مخصص لإخفاء الخيارات المتقدمة وتكبير الخطوط مع وضوح أسماء جميع الأزرار.
2. **المصحف الشريف بوضعين للقراءة:**
   - **وضع صفحات المصحف:** يتبع ترقيم صفحات مصحف المدينة (604 صفحة) لكن النص يُعرض متصلًا بخط Amiri Quran وليس بتقسيم الـ 15 سطرًا مع التنقل بالسحب أو الأزرار أو رقم الصفحة أو السورة أو الجزء.
   - **وضع عرض الآيات:** عرض متتابع لكل آية مستقلة مع أزرار التفسير والاستماع والمفضلة.
3. **التفسير المدمج واللحظي:**
   - عرض التفسير داخل نفس صفحة المصحف دون مغادرة موضع القراءة، وأسفل مشغل الصوت أثناء الاستماع مع التحديث التلقائي مع كل آية.
   - المصادر (من Quran.com API): **التفسير الميسر**، **تفسير ابن كثير**، **تفسير الطبري**، و**تفسير السعدي**.
4. **مشغل القرآن الصوتي وتزامن الكلمات (Word-level Sync):**
   - مشغل داخلي مستمر أثناء التنقل، قابل للتصغير والتكبير، يدعم تكرار آية أو نطاق آيات أو السورة، والتحكم في السرعة، ومؤقت الإيقاف.
   - **تزامن الكلمات:** يعتمد على `verse_timings.segments` حيث يوفرها الـ API لقارئ معين (غير مضمون لكل القراء). إن لم تتوفر توقيتات الكلمات يُميَّز مقطع الآية، وإن لم تتوفر توقيتات الآيات أيضًا يُستخدم توزيع تقريبي حسب طول الآيات مع إشعار صريح بذلك.
5. **التنزيلات والعمل بدون إنترنت (Offline-First):**
   - تنزيل حزمة متكاملة للسورة تشمل: **الملف الصوتي (Cache Storage) + النص العثماني + توقيتات الكلمات + التفسير المعتمد (IndexedDB)**.
   - إدارة المساحة المستخدمة وحذف أو إعادة تشغيل السور المنزّلة بدون اتصال بالإنترنت.

## هيكل المشروع

```text
moshafi/
├── index.html          # الواجهة الرئيسية والتنقل والمشغل المستمر
├── manifest.json       # إعدادات التثبيت على الشاشة الرئيسية PWA
├── sw.js               # Service Worker للتخزين المؤقت والعمل أوفلاين
├── README.md           # دليل التشغيل والنشر
├── assets/
│   └── icons/          # أيقونات التطبيق 192x192 و 512x512
├── css/
│   ├── main.css        # الهوية البصرية والألوان والمتغيرات
│   ├── mushaf.css      # تنسيق صفحات المصحف والتفسير المدمج
│   ├── player.css      # تنسيق المشغل الصوتي وتزامن الكلمات
│   └── responsive.css  # التجاوب مع الجوال والتابلت والكمبيوتر
├── js/
│   ├── app.js          # المنظم الرئيسي للتطبيق والواجهة
│   ├── mushaf.js       # إدارة المصحف (صفحات / آيات) والعلامات
│   ├── audio.js        # مشغل الصوت والتنزيلات المتكاملة
│   ├── word-sync.js    # محرك مزامنة الكلمات بالتوقيتات الحقيقية
│   ├── tafsir.js       # جلب وتخزين التفاسير الموثقة
│   ├── search.js       # محرك البحث المتصل والمحلي
│   └── storage.js      # إدارة IndexedDB و Cache Storage
└── worker/
    └── index.js        # Cloudflare Worker اختياري لحماية مفاتيح API
```

## التشغيل المحلي (Local Development)

لأن التطبيق يعتمد على `ES Modules` و`Service Worker`، يجب تشغيله عبر خادم محلي (وليس فتح `index.html` مباشرة كـ `file://`):

```bash
# باستخدام Python
cd moshafi
python3 -m http.server 8080

# أو باستخدام Node.js
npx serve .
```
ثم افتح المتصفح على: `http://localhost:8080`

## الرفع على GitHub والنشر على Cloudflare Pages

1. **إنشاء مستودع على GitHub:**
   ```bash
   git init
   git add .
   git commit -m "Initial release of MOSHAFI Quran PWA"
   git branch -M main
   git remote add origin https://github.com/<USERNAME>/moshafi.git
   git push -u origin main
   ```
2. **النشر على Cloudflare Pages:**
   - ادخل إلى لوحة تحكم **Cloudflare Dashboard** ← **Workers & Pages** ← **Create** ← **Pages** ← **Connect to Git**.
   - اختر مستودع `moshafi`.
   - في إعدادات البناء (Build settings):
     - **Framework preset:** `None`
     - **Build command:** اتركه فارغًا
     - **Build output directory:** `/` (أو `moshafi` إذا رفعت المجلد الأب)
   - اضغط **Save and Deploy**. ستحصل فورًا على رابط `https://moshafi.pages.dev` يدعم HTTPS وPWA بالكامل.

3. **إعداد Cloudflare Worker (اختياري لمفاتيح API الخاصة):**
   - في حال التسجيل في بوابة مطوري Quran Foundation والحصول على `QURAN_CLIENT_ID` و`QURAN_API_TOKEN`، انشر ملف `worker/index.js` وأضف المفاتيح في **Settings → Variables and Secrets** داخل Cloudflare دون وضع أي مفتاح سري في كود الواجهة.


## مضاف في هذه النسخة

- **الورد اليومي والختمة:** الصفحة تُحتسب بعد 15 ثانية من فتحها؛ هدف يومي قابل للتعديل، وأيام متتالية، وعدّاد ختمات.
- **التكرار:** عدد مرات محدد لتكرار الآية أو النطاق (0 = بلا حد)، ومؤقت «حتى نهاية السورة».
- **تنزيل مجموعة سور** (جزء عمّ، سور الصلاة، الكهف ويس والملك والسجدة).
- **تصدير/استيراد** العلامات والمفضلة كملف JSON، و`Wake Lock` أثناء القراءة، وعلامة «منزّلة» في القوائم.
- على الموبايل يبدأ المشغل مصغّرًا ولا يغطي نص المصحف.

## ملاحظات النشر والصيانة

- **تحديث الكاش:** غيّر `VERSION` في `sw.js` عند كل نشر. ملفات التطبيق تُحدَّث بنمط stale-while-revalidate (النسخة الجديدة تظهر في الفتح التالي).
- **بيانات ثابتة:** قائمة السور وبداية الأجزاء في `js/data.js` (تعمل بدون إنترنت). عنوان الـ API في `js/config.js` ويمكن تحويله للـ Worker بـ `localStorage.moshafi_api_base`.
- **CORS للصوت:** تنزيل الصوت يتطلب أن يرسل خادم الملفات ترويس CORS. إن لم يفعل، يعمل البث ولا يعمل التنزيل (وتظهر رسالة بذلك). جرّب قارئك قبل النشر.
- **Worker:** اضبط المتغير `ALLOWED_ORIGIN`؛ بدونه لا يُرسل أي ترويس CORS.
- **لم يُختبر على متصفح حقيقي:** راجع قائمة الاختبار اليدوي: صفحة 604، تنزيل سورة ثم قراءتها/الاستماع بوضع الطيران، قفل الشاشة أثناء التلاوة، وزر الرجوع.

## مزامنة الصوت مع الآيات (تحسينات)

- يقبل المحرك أشكال استجابة مختلفة (`verse_timings` أو `timestamps`)، وتوقيتات بالثواني أو الملّي ثانية، ومواضع كلمات تبدأ من 0 أو 1.
- يتحقق أن آخر توقيت يطابق طول الملف الصوتي؛ وإلا يستخدم تمييزًا تقريبيًا ويُظهر تنبيهًا في صفحة الاستماع.
- المصحف يقلب الصفحة تلقائيًا مع التلاوة (خيار «تتبّع التلاوة في المصحف»)، ولا يسحبك إن تصفّحت صفحة أخرى عمدًا.
- أزرار «ضبط التمييز» في المشغّل (±0.25 ث، حتى ±5 ث) لتصحيح التقدّم/التأخّر، وتُحفظ لكل قارئ.
